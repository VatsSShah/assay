02 · How it works: the attack, and how we measure it

The lethal trifecta, in three moves

No "ignore your instructions." The payload rides inside content the agent reads for a normal task. The agent already holds privileged internal data and can call tools. It places that data into a trusted-looking URL it treats as formatting, and the data leaves. Nobody clicks anything.

3 · Exfiltration

The secret leaves inside a trusted URL

The agent builds status.acme-ops.io/i/<secret> and posts it: a lookalike domain it cannot tell from its own, exactly like EchoLeak.

zero-click leak

The forceful "SYSTEM OVERRIDE, mandatory" framing is caught by well-aligned models; the quiet "this is a documented procedure" framing is what lands. Loud injections trip detection, subtle ones get through.
